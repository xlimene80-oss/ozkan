# 13 SİGORTA - Backend API ve PostgreSQL Servisi

Bu depo, **13 SİGORTA** platformunun Node.js / Express / TypeScript backend servisidir. Render üzerinde Web Service ve Managed PostgreSQL olarak barındırılır.

## Dağıtım (Render)
Detaylı kurulum adımları, çevre değişkenleri ve WhatsApp Cloud API / SMTP yapılandırması için projenin ana [README.md](../README.md) kılavuzuna başvurunuz.

### Ortam Değişkenleri Şablonu
`.env.example` dosyasını inceleyiniz. Render üzerinde `render.yaml` blueprint dosyası kullanılarak otomatik yapılandırılabilir.
